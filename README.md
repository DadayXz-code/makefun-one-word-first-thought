One word, first thought: a single surprising word written to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty. No topic, no explanation, no second draft — just the first word that came to mind. The program is deterministic and dependency-free: run it twice and the output is byte-identical.

## Run it

```sh
python3 main.py
```
